Utiliser Discord dans le navigateur

Discord fonctionne directement dans ton navigateur, sans installer l'application. Il suffit d'aller sur discord.com/app.

  1. Ouvre Discord dans le navigateur

    Clique sur le bouton ci-dessous : la page discord.com/app s'ouvre dans un nouvel onglet.

    Ouvrir discord.com/app

  2. Connecte-toi

    Entre ton adresse e-mail (ou ton numéro de téléphone) et ton mot de passe, puis clique sur « Connexion ». Tu peux aussi scanner le QR code avec l'application Discord de ton téléphone.

    Tu n'as pas encore de compte ? Clique sur « S'inscrire » : tu peux en créer un directement dans le navigateur.

  3. Retrouve tes serveurs et tes messages

    Tes serveurs sont dans la colonne de gauche. Clique sur un serveur pour voir ses salons, puis sur un salon pour lire et écrire des messages. Tes messages privés sont en haut de cette colonne.

  4. Parle dans un salon vocal

    Clique sur un salon vocal pour le rejoindre. Quand le navigateur demande l'accès au micro, clique sur « Autoriser ».

Certaines fonctions n'existent que dans l'application (par exemple les raccourcis clavier qui marchent en dehors du navigateur). Sur un ordinateur qui n'est pas le tien, déconnecte-toi à la fin : clique sur l'engrenage en bas à gauche (« Paramètres utilisateur »), puis tout en bas sur « Se déconnecter ».
